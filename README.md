# ADETEX — Instalador y actualizaciones

Este repositorio solo guarda los **instaladores** del programa ADETEX (el código es privado).

## Instalar en una PC

1. Abre la última versión: https://github.com/Lynch-JF/Retailsystems-Adetex-Realese/releases/latest
2. Descarga **`Adetex-win-Setup.exe`** y ejecútalo.

Después de instalado, el programa revisa si hay una versión nueva cada vez que entra un
**Admin** y pregunta antes de actualizar y reiniciar.

## Requisitos

- Windows 10 u 11 con .NET Framework 4.7.2 o superior (viene incluido en Windows 10/11 actualizados).
- Conexión a internet (el programa trabaja con la API de ADETEX en Railway).

Las versiones se publican automáticamente desde el repositorio del programa (GitHub Actions).
